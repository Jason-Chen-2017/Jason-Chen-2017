系统概述

本系统是一个完整的 AI 驱动的研发自动化平台，整合了 OpenClaw 和 Claude Code 两大 AI Agent 引擎，实现从需求分析到 UI 自动化测试验收的全流程自动化研发。系统支持多角色 Agents 协同工作，并在关键节点提供人机协同能力，通过 Jenkins CI/CD + Docker + Kubernetes 实现企业级 DevOps 自动化部署。
