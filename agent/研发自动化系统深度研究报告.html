🔍

人机协同节点

在以下关键阶段设置人工审核点，确保质量和方向正确：

  • PRD 确认后: 产品负责人审核需求文档
  • 架构设计后: 技术委员会评审架构方案
  • API 设计后: 前后端负责人确认接口规范
  • 代码审查后: Tech Lead 批准代码合并
  • 部署前: 运维团队确认部署方案
