核心模块详解

1. 任务触发机制 (Task Trigger)

支持多种触发方式，满足不同场景需求：

  • Webhook 触发 - GitHub/GitLabIssue/PR/Merge事件，自定义Webhook
  • Cron 定时触发 - 支持标准 Cron 表达式，灵活调度
  • API 触发 - RESTful API 接口，支持优先级控制
  • Chat 命令触发 - Slack/飞书/Discord聊天命令，便捷交互
POST /api/v1/triggers/webhook - Webhook 端点
POST /api/v1/triggers/api - API 触发端点
POST /api/v1/triggers/chat/{platform} - Chat 命令端点
POST /api/v1/triggers/cron - Cron 任务创建端点

2. 状态同步机制 (State Sync)

实时同步各 Agent 节点状态，确保流程一致性：

  • 实时通信 - WebSocket 推送 + Redis Pub/Sub广播
  • 状态持久化 - PostgreSQL 存储任务状态 + MongoDB 存储详细日志
  • 状态机设计 - PENDING → QUEUED → RUNNING → SUCCESS/FAILED/WAITING_APPROVAL
  • 统计监控 - 实时统计任务/Agen t状态，支持仪表盘展示

3. 异常重试机制 (Retry Manager)

智能错误检测与自动重试，保障系统可靠性：

  • 错误分类 - 可重试错误 (网络超时/API 限流/临时故障) vs 不可重试错误 (认证失败/参数错误)
  • 重试策略 - 指数退避 (Exponential Backoff): delay = base × 2^(attempt-1)
  • 最大重试次数 - 默认 3 次，可配置 1-10 次
  • 降级处理 - 备用模型切换 (Claude Sonnet → Opus)、备用执行路径、人工介入通知

部署架构

开发环境 (Docker Compose)

docker-compose.yml 包含:
├── PostgreSQL - 关系型数据库
├── MongoDB - 文档数据库
├── Redis - 缓存与消息队列
├── FastAPI Backend - 后端服务
├── React Frontend - 前端服务
└── OpenClaw Gateway - Agent 网关

生产环境 (Kubernetes)

Kubernetes Cluster:
├── Ingress Controller (Nginx)
├── Backend Deployment (3 replicas)
├── Frontend Deployment (2 replicas)
├── StatefulSet (PostgreSQL/MongoDB)
├── Redis Sentinel
├── Jenkins Master/Agent
└── Monitoring Stack (Prometheus/Grafana)
