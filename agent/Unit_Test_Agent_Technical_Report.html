📋 项目概述

UnitTestAgent 是一个智能单元测试生成系统，基于 OpenClaw 框架和 Claude Code CLI，实现从业务代码到单元测试用例的端到端自动生成。

🎯 核心价值：在现代软件研发中，单元测试是保证代码质量的关键环节。然而，编写高质量的单元测试往往耗时耗力。本项目通过 AI 大模型自动分析代码并生成高质量单元测试，将测试覆盖率提升至 80%+，同时遵循各语言测试框架的最佳实践。

# 生成流程
源代码 → 分析 → Prompt → LLM → 解析 → 验证 → 保存

🔄 工作流程

步骤 1: 代码输入
提供源代码文件路径或目录
步骤 2: 代码分析
CodeAnalysisEngine 分析代码结构，识别可测试单元
步骤 3: 提示词构建
基于分析结果和模板，构建 LLM 提示词
步骤 4: LLM 生成
调用 Claude/OpenAI等大模型生成测试代码
步骤 5: 解析验证
解析 LLM 响应，验证生成的测试质量
步骤 6: 保存输出
保存测试文件，记录反馈到记忆系统

任务编排流程

主任务：generate_unit_tests
├── 子任务 1: analyze_code (代码分析)
│   └── 输出：analysis_result
├── 子任务 2: generate_tests (测试生成)
│   ├── 输入：analysis_result
│   └── 输出：generated_tests
└── 子任务 3: validate_tests (测试验证)
    ├── 输入：generated_tests
    └── 输出：validation_result

并发控制：最多 5 个任务并行执行
错误处理：自动重试 3 次，失败后记录日志

💡 应用示例

示例 1: 基本使用

import asyncio
from core import UnitTestAgent

async def main():
    agent = UnitTestAgent()
    
    result = await agent.generate_unit_tests(
        code_path='src/calculator.py',
        output_path='tests/'
    )
    
    print(f"Success: {result['success']}")
    if result['success']:
        print(f"Tests saved to: {result['output_path']}")

asyncio.run(main())

示例 2: 批量生成

from pathlib import Path

# 获取所有 Python 源文件
src_dir = Path('src')
python_files = list(src_dir.glob('**/*.py'))

# 批量生成
tasks = [
    agent.generate_unit_tests(code_path=str(file))
    for file in python_files
]

results = await asyncio.gather(*tasks, return_exceptions=True)

# 统计结果
success_count = sum(1 for r in results 
                    if isinstance(r, dict) and r.get('success'))
print(f"生成完成：{success_count}/{len(python_files)} 成功")

生成的测试示例

"""Calculator 模块的单元测试"""

import pytest
from src.calculator import Calculator


class TestCalculator:
    
    def setup_method(self):
        """每个测试前的设置"""
        self.calc = Calculator()
    
    def test_add_positive_numbers(self):
        """测试两个正数相加"""
        result = self.calc.add(5, 3)
        assert result == 8
    
    def test_divide_by_zero(self):
        """测试除以零异常"""
        with pytest.raises(ValueError) as exc_info:
            self.calc.divide(10, 0)
        assert "除数不能为零" in str(exc_info.value)
    
    def test_divide_floats(self):
        """测试浮点数除法"""
        result = self.calc.divide(7.5, 2.5)
        assert abs(result - 3.0) < 0.001
