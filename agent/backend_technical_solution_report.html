🔄 CI/CD 流程

持续集成流水线

1️⃣ 代码提交

开发者推送代码到 Git 仓库，触发 Webhook

2️⃣ 代码检查

执行 Lint 检查、类型检查、安全扫描

3️⃣ 单元测试

运行单元测试，生成覆盖率报告

4️⃣ 构建镜像

构建 Docker 镜像并推送到 Harbor

5️⃣ 部署测试

部署到测试环境，执行集成测试

6️⃣ 生产发布

人工审批后，部署到生产环境

⚠️ 关键控制点：
  • 生产环境部署需要人工审批
  • 部署前自动执行健康检查
  • 支持一键回滚到历史版本
  • 部署过程全链路监控
