RESTful / GraphQL API 设计规范

RESTful 设计原则

  • 资源导向 URL (名词，非动词)
  • 正确使用 HTTP 方法
  • 统一的状态码规范
  • 支持分页、过滤、排序
  • 版本控制 (/api/v1/, /api/v2/)
  • 一致的命名约定

GraphQL 设计原则

  • 直观的 Schema 结构
  • 正确的命名约定
  • 游标分页实现
  • 优雅的错误处理
  • 性能优化 (避免 N+1)
  • 完整的类型文档
