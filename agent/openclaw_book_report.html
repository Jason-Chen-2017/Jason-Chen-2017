CHAPTER 01

OpenClaw 入门与核心概念

全面认识 OpenClaw——这款革命性的 AI 智能体工具，理解其核心价值、发展历程和架构组成。

📌 核心要点

什么是 OpenClaw？

OpenClaw（中文昵称"小龙虾"）是一款开源的、本地优先部署的 AI 智能体网关工具。它的核心定位是将大语言模型的推理能力与实际任务执行能力深度结合，实现从"能说"到"能做"的质的飞跃。

🔑 五大核心优势

优势 说明 价值
🔒 数据隐私保障 完全本地部署，数据不出域 符合企业合规要求
💻 本地资源访问 直接访问文件系统和本地应用 突破云端 AI 限制
🔌 无限功能扩展 1700+ 技能，支持自定义开发 满足个性化需求
🌐 多平台无缝适配 支持飞书/企微/钉钉/QQ 等 统一用户体验
💰 成本可控优化 混合模型策略，本地模型零成本 降低 86% 使用成本

安装部署与环境配置

详细讲解 OpenClaw 的安装部署全流程，涵盖多平台安装方案、模型配置、通信通道集成等内容。

🖥️ 系统要求

配置等级 CPU 内存 存储 适用场景
最低配置 4 核 4 GB 20 GB SSD 个人轻量使用
推荐配置 8 核 16 GB 100 GB SSD 个人重度/小团队
企业配置 16 核+ 32 GB+ 500 GB+ NVMe 中大型团队

📦 一键安装

# Linux/macOS
curl -fsSL https://openclaw.ai/install.sh | bash

# Windows PowerShell
Invoke-WebRequest -Uri "https://openclaw.ai/install.ps1" -OutFile "install.ps1"
.\install.ps1

🐳 Docker 部署

docker run -d \
  --name openclaw \
  -p 3000:3000 \
  -v ~/openclaw/config:/app/config \
  -v ~/openclaw/data:/app/data \
  -e ANTHROPIC_API_KEY=sk-xxx \
  openclaw/openclaw:latest

⚙️ 模型配置

支持的模型提供商

  • 国际模型：Claude 3.5、GPT-4 Turbo、Gemini
  • 国产模型：腾讯混元、通义千问、智谱 AI
  • 本地模型：Ollama (Llama 3、Qwen)、LM Studio

✅ 安全最佳实践清单

  • 启用所有通信的 TLS 加密（TLS 1.3+）
  • 实施最小权限原则
  • 定期轮换密钥和凭证（90 天）
  • 启用完整的审计日志
  • 建立漏洞管理流程
  • 制定并测试应急预案
  • 定期进行安全培训
