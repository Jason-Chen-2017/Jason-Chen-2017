安装 OpenClaw

# 方法 1: 官方安装脚本（推荐）

# 方法 2: npm 全局安装
npm install -g openclaw@latest

# 或使用 pnpm（更快更节省空间）
pnpm add -g openclaw@latest
# PowerShell 安装脚本
iwr -useb https://openclaw.ai/install.ps1 | iex

# 或使用 npm
npm install -g openclaw@latest
# 拉取镜像
docker pull openclaw/gateway:latest

# 运行容器
docker run -d \
--name openclaw \
-p 18789:18789 \
-v ~/.openclaw:/root/.openclaw \
-e OPENCLAW_PASSWORD="your-password" \
-e OPENAI_API_KEY="sk-xxx" \
openclaw/gateway:latest

帮我创建一个 Python 脚本，计算斐波那契数列的前 20 项，并保存到 fibonacci.py
✅ 任务完成！

我已创建 fibonacci.py 文件，内容如下：
```python
def fibonacci(n):
"""生成斐波那契数列的前 n 项"""
if n <= 0:
return []
elif n == 1:
return [0]

sequence = [0, 1]
for i in range(2, n):
sequence.append(sequence[-1] + sequence[-2])
return sequence

# 计算前 20 项
result = fibonacci(20)
print(result)
```
